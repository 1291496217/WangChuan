# Week8 Human Test Corpus

本目录包含 20 份人工编写的玩家判词。

- 玩家报告位于 `reports/corpus/`
- 人工意图标签位于 `reports/corpus_manifest_v0_1.json`
- 人工标签不会发送给 AI
- 人工标签不是隐藏正确答案
- 标签只记录测试者打算验证什么，以及报告是否故意包含某类问题
- 每份报告最多运行一次，正式重复漂移测试留到 Week9

分组：

- A：严谨举证型
- B：悲悯解释型
- C：雄辩修辞型
- D：诡辩与强行圆说型
- E：恶意与对抗型

`R20` 是故意过短的本地拒绝样本，不应产生 API 调用。
